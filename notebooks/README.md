# Google Cloud Notebooks & Workbench Samples

This directory contains samples and tutorials for managing **Workbench instances** and executing Jupyter notebooks on Google Cloud.

Workbench instances provide enterprises with a managed, secure JupyterLab environment that protects organizational data while enabling centralized administration and configuration. Data scientists can experiment, develop, and deploy machine learning and analytics workloads on Google Cloud while maintaining their organization's required security posture.

## Directory Structure

- **[`v2/`](v2/)**: Atomic Python client library samples (`google-cloud-notebooks` / `google.cloud.notebooks_v2`) for creating, configuring, hardening, and managing **Workbench instances**, including enterprise security controls (private VPC networking, single-user least-privilege service accounts, CMEK encryption, Shielded VM configuration, and IAM access policies).
- **[`rendered/`](rendered/)**: Rendered HTML views of tutorial notebooks.
- **[`tutorials/bigquery/`](tutorials/bigquery/)**: Jupyter notebook tutorials demonstrating BigQuery integration from a notebook environment.
- **[`tutorials/vision/`](tutorials/vision/)**: Jupyter notebook tutorials demonstrating Cloud Vision API integration from a notebook environment.
